
# 🍝 Bella Cucina

### A Taste of Italy, Crafted with Passion.

Bella Cucina is a premium Italian restaurant website designed to deliver an elegant and engaging dining experience. It showcases signature dishes, restaurant ambience, and an interactive table reservation form.

## ✨ Features

- Premium dark-themed design with elegant gold accents.
- Responsive navigation and smooth section navigation.
- Hero section with menu navigation.
- Signature menu with food images and pricing.
- Restaurant story and gallery sections.
- Interactive reservation form.
- Form validation, including 10-digit phone number validation.
- Contact information and opening hours.
- Elegant footer with quick navigation links.

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS v4
- Vite
- Lucide React

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shivanshbhargava-prog/bella-cucina.git
```

### 2. Navigate to the project directory

```bash
cd bella-cucina
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
